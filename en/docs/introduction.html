Introduction

Welcome! 🎲 Here's your companion for adventures on Discord: a versatile bot designed to make your role-playing game sessions smoother and more enjoyable.

This page introduces the bot's basic syntax, the one you will use in every game session, then points you to the rest of the documentation.

Rolling a die​

Dicelette reads your messages directly: you don't need a command to roll a die. Three notations exist, depending on what you want to do with your message.

NotationExampleResult
Direct1d20Your message is deleted and replaced by the result, sent in the channel and in the log.
IndirectI force the door [1d20]Your message is kept. Only the content of the brackets is rolled: the bot replies with the result, and the log contains a link to your original message.
Semi-direct1d20 I force the doorThe first die found is rolled, and the rest of the message is sent to the log as a comment.

You can also use the /roll slash command (e.g. /roll 1d20+3). In every case, results are gathered in a thread prefixed with 🎲, the log: see the default behavior.

For more details on the three notations, see Sending message and the basic commands.

Comments​

A comment adds context to a roll: it is displayed along with the result. Depending on what you want to annotate, there are several ways to write one.

  • Global comment: #comment. Placed at the end of the dice, it annotates the whole roll. In a direct message, the # can be omitted: this is what makes the semi-direct notation possible.

    Example
    • /roll 1d20+5 #Attack
    • 1d20 I force the door

  • Line comment: [comment]. In a shared roll (;&), it annotates a specific formula.

    Example

  • Editing a comment afterwards: ///. Reply to the result message with /// My comment. Only your own comments can be edited, on every result rolled by the bot (slash command or message). /// is the default prefix: it can be changed.

With the shared roll example above, the result displays the global comment first, and the underlined line comment in front of the relevant formula:

1d20;&-2 [hp loss] #comment

comment
※ 1d20 ⟶ [2] = 2
◈ hp loss — [1d20]-2 ⟶ [2]-2 = 0

Comments are sensitive to spaces
  • A [bracketed] or #global comment must be preceded by a space.
  • The # of a global comment must be stuck to its text: #Attack.
  • In a shared roll, don't add a space before or after the ; separating the formulas, otherwise the rest will be considered a comment.
Square brackets [] have several meanings
  • In a message, [1d20] is a die to roll (indirect notation).
  • After a shared roll, [text] is a comment.
  • In template dice, macros and snippets, [value] is a number treated as a statistic: see the Syntax page.

Statistics and characters​

If you have registered a character sheet (or attributes), you can use your statistics directly in a roll:

  • $statistic: value of a statistic, for example 1d20 + $strength. To use it as a number of dice, write ($strength)d20.
  • @character: rolls the die with a specific character, for example 1d100 @Bob.

Moderators can also mention a player in a direct message to roll a die on their behalf.

To create your first character, see Template and Registering an user.

Successes and failures​

When a die is followed by a comparison sign (>, <, =…), the bot compares the result and tells you whether it is a success or a failure. With 1d20>10:

Success — 1d20 ⟶ [20] = [20] > 10
  • To add an opposition, stack the signs: 1d100>20>10 (the last one is the opposition).
  • To count the dice that pass a comparison instead of comparing the total, put them in curly braces: {3d12>20}.

The details of these rules are in the Dice Notations page.

Going further with rolls​

  • Shared rolls: 1d20;&+5;&*2 rolls a single die and applies several formulas to it. → Shared unique rolls
  • Bulk rolls: 4#2d10 repeats the roll four times. → Bulk rolls
  • Mathematical expressions: 1d6 + {{ceil($ / 2)}}, usable in template dice, /calc, /dbroll, etc. → Mathematical expressions
  • Criticals: {cs:<2} and {cf:>10} define critical success and failure thresholds. → Critical successes and failures
  • Symbols: the full list ($, {exp}, {{...}}, &…) is in the Syntax page.

Reading command syntax​

In the documentation, command fields are described as follows:

  • [field]: mandatory.
  • (field): optional.
  • (*field): auto-completed.
  • @field: a mention (user or role, depending on the command).
  • #field: a channel.
  • ?field: a true/false value.

For example, /roll (dice) (?hidden) is a command whose two fields are optional, the second one being a true/false value. See the Syntax page for character auto-completion.

Main Features​

🎲 Advanced Dice System​

  • Flexible dice rolls: Full support for complex expressions to support all types of rolls.
  • Custom dice: Create and use dice specific to your characters and campaigns.
  • Automatic result management: Results can be organized in dedicated threads to avoid clutter, or sent to a specific channel.

📊 Complete Character Management​

  • Server templates: Configure a unique template adapted to your system.
  • Character sheets: Simple registration with an intuitive interface.
  • Dynamic statistics: Modify and update your characters.
  • Multi-character: Manage multiple characters per user.
  • Private sheets: Control the visibility of character information.

🔧 Flexible Server Configuration​

  • Customizable settings: Adapt the bot to your needs with numerous configuration options.
  • Auto-roles: Automatic role assignment for simplified permission management.
  • Logging: Track modifications and error management
  • Self-registration: Allow players to register their own characters
  • OOC message removal: Automatic cleanup of out-of-character messages
  • Display options: Customize result display (timestamps, deletion delays, anchor links...)
  • Multilingual support: Interface available in French and English

🎭 Game Master Features1​

  • Rolls for players: Make rolls on behalf of your players.
  • Hidden rolls: Make secret rolls hidden from players to maintain suspense.

🛠️ Practical Tools​

  • Import/Export: Save and transfer your data easily
  • Integrated help system: Quick access to documentation and guides
  • Automatic cleanup: Intelligent management of obsolete data
  • Intuitive user interface: Forms and interactive menus to simplify usage

Your data​

Dicelette only keeps the essentials (message IDs, links between players and characters, server settings and templates): your character sheets stay in your Discord messages. For details on storage, automatic cleanup and how to request the deletion of your data, see the Technical overview.
